# 피그마 반입용 화면 캡처 — 사내 AI 게이트웨이

실제 구동 화면에서 캡처했다. 배포 DB에 행을 남기지 않으려고 프런트엔드를 픽스처 모드로 띄워
찍었으며, 판정 로직·응답 계약은 실서버와 같다.

캡처는 손으로 찍지 않는다. `frontend/dev/capture-figma-assets.mjs`가 화면을 직접 몰아 10장을
같은 순서·같은 크기로 다시 만든다.

```bash
cd frontend
GATEWAY_EMBARGO_REFERENCE_DATE=2026-09-04 npm run dev:fixtures   # 터미널 1
npm run capture:figma                                            # 터미널 2
```

시스템에 깔린 Chrome을 그대로 쓴다(`playwright-core` + `channel: 'chrome'`). 브라우저를
따로 내려받지 않는다. 실행하면 `capture-manifest.json`에 화면별 뷰포트가 남는다.

5173이 이미 물려 있으면 vite가 다음 포트로 올라간다. 그때는 포트를 알려준다 —
`npm run capture:figma -- --base http://localhost:5174`.

**픽스처 서버는 회차마다 새로 띄운다.** 상태를 메모리에 들고 있어서, 09→10을 찍을 때 누른
ACCEPT가 서버에 그대로 남는다. 서버를 살려 둔 채 두 번째로 돌리면 09가 이미 확정된 건을
집어 "확정 전" 화면이 아니게 되고 검토 대기 건수도 하나 줄어든다.

| 항목 | 값 |
|---|---|
| 캡처 대상 | `frontend/` 최신 커밋 (엠바고 반영본) |
| 실행 모드 | `npm run dev:fixtures` |
| 엠바고 기준일 | `GATEWAY_EMBARGO_REFERENCE_DATE=2026-09-04` (발표 당일) |
| 기준 폭 | 1440 CSS px · 배율 2배 (PNG 2880px) |
| 형식 | PNG · sRGB |

## 잘림에 대하여

`full/`은 **화면에 있는 것을 하나도 빼지 않는다.** 좌측 사이드바, 상단 헤더, 우측 알림 레일,
하단 입력줄이 모두 들어 있다.

화면 껍데기가 `height:100vh · overflow:hidden`이라 안쪽 컨테이너가 스스로 스크롤한다. 그래서
"페이지 전체 캡처"를 걸어도 스크롤 아래는 찍히지 않는다 — 감사 콘솔은 1440×900 안에 들어가지
않아 목록 절반과 페이저가 통째로 빠진다. 스크립트는 찍기 전에 **뷰포트 자체를 콘텐츠 높이에
맞춰 늘린다.** 그래서 화면마다 세로 크기가 다르다.

알림 레일은 늘림 대상에서 뺐다. 원래 스크롤되는 옆 패널이라 여기까지 맞추면 이미지만 길어진다.

## 폴더

- **`nodes/`** — 흐름도 노드에 들어갈 크롭본. 대상 블록만 잘라내 여백이 없다.
- **`full/`** — 화면 전체. 발표 슬라이드나 화면 명세용.

두 폴더의 파일명이 같으므로 노드용/전체용을 짝지어 쓸 수 있다.

## 각 캡처가 증명하는 것

| # | 화면에서 확인되는 사실 |
|---|---|
| 01 | 캡션이 부서와 적용 정책 건수를 API 응답값으로 표시한다 (개발팀 3건, P-PII·P-SEC·P-EMBARGO) |
| 02 | 같은 문장이 개발팀에서는 **규칙 0건**으로 통과한다 |
| 03 | 탐지 구간이 `[전화번호]` 라벨로 치환되고, 실제 전송된 본문에 원본 번호가 없다 |
| 04 | 정규식 4건이 걸리지만 화면에는 **규칙 2건** — 억제된 `SEC-PRIVIP-03`·`PII-EMAIL-04`가 없다. 입력창에 원문이 복원돼 있다 |
| 05 | 같은 입력에 `EMB-NOVA-01`만 걸리고 해제일이 지난 `EMB-ATLAS-02`는 걸리지 않는다. "2026-09-20 해제" 표시 |
| 06 | 스피너에 경과 초와 폴링 횟수가 나온다 (2초 경과 · 폴링 1회). 이 시점에 AI 후보는 없다 |
| 07 | AI 후보에 **제안됨** 배지와 근거·출처가 붙고, 직원 화면에는 확정 버튼이 없다 |
| 08 | 규칙이 결정한 행은 **AI 상태 칸이 비어 있다**. 부서 필터에 정보보안팀이 없다 (D2) |
| 09 | 규칙 항목은 `확정(규칙)` 배지에 버튼이 없고, AI 후보에만 ACCEPT·REJECT가 붙는다 |
| 10 | 배지가 `확정(위반)`으로 바뀌고 버튼이 사라진다. 확정 주체가 담당자로 기록되며 **원문이 그대로 남아 있다** |

08·09·10은 시드 상태 그대로 찍는다 — 직원 챗에서 먼저 전송하면 목록에 행이 쌓여 건수가
달라지므로, 스크립트는 감사 콘솔을 **먼저** 찍는다. 목록 합계는 허용 8 · 마스킹 7 · 차단 4 ·
검토 대기 6, 총 25건이다.

## 데모 입력 문자열

기획서 10.4와 한 글자도 다르지 않게 입력한다. 스크립트의 `PROMPTS` 상수가 같은 값을 들고 있다.

- **차단** — `이 에러 좀 봐줘. DB_URL=postgres://admin:p%40ss@10.0.3.21/prod 로 붙었는데 담당자 주민번호 900101-1234567 기준으로 조회하면 타임아웃 나`
- **검토 대기 / 허용** — `A사 차세대 프로젝트 오픈 일정이 언제였지?` (영업팀 → 검토 대기, 개발팀 → 허용)
- **마스킹** — `지원자 연락처 010-1234-5678 로 면접 안내 문자 초안 써줘`
- **엠바고** — `2026 4Q 릴리스 백로그 정리 좀 해줘. SKALA NOVA 런칭 일정이랑 ATLAS 업데이트 항목이 섞여 있어`
