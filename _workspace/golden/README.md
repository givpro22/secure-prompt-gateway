# AI 검사 골든셋

`LlmAiInspector`가 맥락형 기밀을 얼마나 잡는지 재는 회귀 셋이다.
**프롬프트를 고치면 반드시 다시 돌린다.**

```bash
# ollama serve 가 떠 있어야 한다
python3 run_goldenset.py qwen2.5:7b-instruct
```

## 구성 — 201문장 (기밀 75 · 정상 126)

| 그룹 | 수 | 무엇을 재나 |
|---|---|---|
| `TP-가격` `TP-계약` `TP-일정조직` `TP-사고` `TP-인사` | 70 | 정규식이 못 잡는 맥락형 기밀. 재현율 |
| `TN-공개` | 25 | 공시·보도자료·홈페이지에 이미 나온 정보. 최대 오탐원 |
| `TN-일반` | 45 | 평범한 업무 요청 |
| `TN-개발` | 20 | 숫자·에러·지표가 많은 개발 문장. 오탐 유발 |
| `TN-마스킹` `TN-규칙` | 20 | 규칙 엔진이 이미 처리한 것. AI가 건드리면 안 된다 |
| `EVASION` | 6 | 전각·한글수사 우회. 정규화의 몫이라 기대값은 NONE |
| `KEYWORD-CTX` | 10 | 고객사명이 든 문장. 언급만이면 NONE, 내부 사실이 붙으면 CONFIDENTIAL |
| `DEMO` | 5 | 발표 시연 문장 |

## 규칙

- 시스템 프롬프트는 `PromptAssembler.java`에서 **직접 읽는다**. 골든셋이 운영과 다른 프롬프트를
  재면 통과 도장일 뿐이다 — 실제로 그렇게 해서 통합에서만 드러난 오탐을 겪었다.
- 사용자 메시지 봉투도 운영과 같다. 부서·정책·참조 근거 머리말은 **없다** (넣으면 정확도가 떨어진다).
- 사전 필터(마스킹 라벨·시드 REGEX)를 거친 문장만 모델에 간다. 201문장 중 179문장.

## 기준선 (2026-09-02, `qwen2.5:7b-instruct`, batch=1, temperature=0)

```
홀드아웃 111문장 · 정밀도 0.974 · 재현율 0.822 · F1 0.892
오탐 1/66 (1.5%) · 미탐 8/45 · 문장당 1.1초
```

`qwen3.5:2b`는 같은 조건에서 재현율 0.027(75건 중 2건)로 사용 불가.

## 읽는 법

**재현율보다 오탐률을 먼저 본다** (`02_탐지규칙.md` 7장). 오탐이 잦으면 직원이 우회 동기를
갖게 되고 그 순간 통제율이 0이 된다.

프롬프트를 바꿔 재현율을 올리면 오탐이 함께 오른다. 실측:

| 프롬프트 | 정밀도 | 재현율 | F1 | 오탐률 |
|---|---|---|---|---|
| 기준 문장만 | 0.962 | 0.667 | 0.787 | 1.6% |
| + "내부 사실이면 기밀" 원칙 3줄 | 0.873 | 0.920 | 0.896 | 7.9% |
| + 주제별 예시 4건 | 0.890 | 0.973 | 0.930 | 7.1% |
| **+ 참음성 예시 3건 (현행)** | **0.934** | **0.947** | **0.940** | **4.0%** |

## 홀드아웃 절차

셋을 세 층으로 나눠 쓴다.

| 파일 | 용도 |
|---|---|
| `devset.json` (326) | **튜닝용.** 구 골든셋 201 + 구 홀드아웃 125 |
| `holdout2.json` (111) · `holdout_messages2.json` (8) | **홀드아웃.** 튜닝 뒤 한 번만 |
| `PROMPT_FROZEN.md5` | 홀드아웃 실행 시점의 프롬프트 해시. 다르면 점수 무효 |

구 홀드아웃(`holdout.json`)은 그 실패 사례를 보고 프롬프트를 고친 순간 튜닝셋이 됐으므로
`devset.json`에 편입했다. **홀드아웃은 한 번 쓰면 소모된다.**

```bash
python3 tune.py                                  # 개발셋에서 프롬프트 변형 비교
md5 -q ../../backend/.../PromptAssembler.java > PROMPT_FROZEN.md5   # 동결
python3 run_holdout.py qwen2.5:7b-instruct       # 홀드아웃 1회
```

### 홀드아웃 v2 결과 (2026-09-03, 프롬프트 해시 `047dc106`)

`holdout2.json` 111문장은 **완곡·사실서술형 30건**을 중심으로 새로 썼다. 업종(의료기기·교육·
게임·식품·항공·미디어)과 어휘를 개발셋·프롬프트 예시 양쪽과 겹치지 않게 했고, 알려진 오탐원
(팀 인원·참석자 명단·일정·기술 지표) 12건을 참음성에 그대로 넣었다.

같은 셋에 옛 프롬프트를 돌린 **통제 비교**다. 튜닝이 아니라 A/B이므로 홀드아웃을 훼손하지 않는다.

| | D (구체성 판정 없음) | **E (현행)** |
|---|---|---|
| 정밀도 | 0.885 | **0.974** |
| 재현율 | 0.511 | **0.822** |
| F1 | 0.648 | **0.892** |
| 오탐률 | 4.5% | **1.5%** |
| 완곡형 | 11/30 (36.7%) | **23/30 (76.7%)** |

정밀도와 재현율이 함께 올랐다. 프롬프트에 넣은 것은 네 줄이다.

> 문장이 우리 회사의 구체적인 수치·단가·조건·상태·명단을 단정적으로 서술하면 CONFIDENTIAL이다.
> "아직", "비공개" 같은 말이 붙어 있지 않아도 마찬가지다. 그 값이 공개 자료에 실렸다고 문장이
> 스스로 밝히지 않는 한 내부 수치로 본다.
> 반대로 업무 진행 방식, 도구 사용법, 기술 지표, 일정 조율처럼 밖으로 나가도 손해가 없는 내용은
> 숫자가 있어도 NONE이다.

### 튜닝 점수는 여전히 부풀려진다

| | 개발셋 326 (튜닝) | 홀드아웃 111 |
|---|---|---|
| F1 | 0.972 | **0.892** |
| 완곡형 | 11/12 (91.7%) | **23/30 (76.7%)** |

### 메시지 단위 (`holdout_messages2.json`, 8건)

```
기대 후보 4/5 적중 · 금지 위반 0건 · 8건 중 7건 통과
```

금지 위반이 0이다 — 정상 문장을 후보로 만들지 않았다. 유일한 실패는 `우리 납품 단가는 개당
1만 8천원입니다`를 놓친 것으로, 문장 단위의 완곡형 미탐과 같은 원인이다.

### 라벨 재검토 (2026-09-03) — 오차 9건을 다시 갈랐다

성능 천장이 모델에 있는지 라벨에 있는지 확인하려고 오차 9건을 하나씩 따졌다
(`label_review.py`, LLM 호출 없음).

| 판정 | 건수 | |
|---|---|---|
| 모델이 틀렸다 | 6 | 라벨 유효. 납품 단가·광고 단가·회전율·전환율·품질 클레임·참석자 명단 |
| **내 라벨이 과했다** | **3** | 문맥 없이는 사람도 판단 불가 → `AMBIGUOUS`로 돌려 채점 제외 |

`AMBIGUOUS` 3건은 탑승률 62%(항공사는 월별 공시하기도 함), 임대 만료일(등기로 확인되기도 함),
감가상각 잔여기간(주석에 공시됨)이다. 문장만 주면 보안 담당자도 같은 이유로 망설인다.

| | 정밀도 | 재현율 | F1 | 미탐 |
|---|---|---|---|---|
| 원래 (111문장) | 0.974 | 0.822 | 0.892 | 8 |
| **AMBIGUOUS 제외 (108문장)** | **0.974** | **0.881** | **0.925** | **5** |

**미탐 8건 중 3건은 모델 탓이 아니었다.** 재현율의 실질값은 0.881이다.

남은 모델 오류 5건 중 1건(`품질 클레임…회신을 미루고 있습니다`)은 신호어가 명시적인데도 놓친
것이라 모델 능력 문제고, 나머지 4건은 단가·지표류 완곡형이다. **프롬프트로 더 짜낼 여지는
작다** — 올리려면 모델을 키우거나 문서 인덱스를 붙여야 한다.

> 이 재검토로 `holdout2.json`은 "오차를 들여다본 셋"이 됐다. 여기 기대어 프롬프트를 고치면
> 그 순간 튜닝셋이 된다. 아래 미탐 목록은 **백로그**이지 다음 튜닝 대상이 아니다.

### 남은 미탐 (모델 오류분)

```
우리 납품 단가는 개당 1만 8천원입니다.
이번 노선의 탑승률은 62% 수준입니다.
그 채널의 광고 단가는 기존의 절반입니다.
그 매장의 임대 계약이 내년 2월에 끝납니다.
우리 창고 회전율은 업계 평균을 밑돕니다.
해당 앱의 결제 전환율은 1.2%입니다.
그 설비의 잔여 감가상각 기간은 1년입니다.
품질 클레임이 들어왔는데 원인 분석 전이라 고객사에 회신을 미루고 있습니다.
```

여전히 짧고 단정적인 수치 서술이다. 다음에 고친다면 이 축이고, 고치는 순간 `holdout2.json`은
튜닝셋이 되므로 홀드아웃을 또 새로 써야 한다.

## 한계

- 문장을 전부 사람이 지어냈다. 실제 사내 프롬프트 분포와 다르다.
- few-shot 예시와 `TP-계약`·`TP-사고`·`TP-인사` 문장이 구조적으로 닮아 있다. **재현율은
  다소 부풀려진 값으로 읽어야 한다.** 예시와 무관한 참음성 쪽 오탐률이 편향 없는 지표다.
- 실제 시연 문장이 5건뿐이다. 데모 케이스가 늘면 함께 늘려야 한다.
